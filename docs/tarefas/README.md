# Planejamento da Entrega 2

Registro histórico de como o trabalho da Entrega 2 foi dividido entre os cinco integrantes
para ser feito em paralelo, cada um com o auxílio de IA.

> **A fonte da verdade é [`docs/SPEC.md`](../SPEC.md).** Estes arquivos mostram como a
> entrega foi planejada e não são atualizados depois dela. Se algo aqui divergir da SPEC,
> vale a SPEC. As decisões D1–D7 do contrato estão registradas na §8 da SPEC.

| Arquivo | O que é |
|---|---|
| [`00-LEIA-PRIMEIRO.md`](00-LEIA-PRIMEIRO.md) | Regras comuns, branches, comandos Git e modelo de PR |
| [`CONTRATO.md`](CONTRATO.md) | Interfaces combinadas entre os módulos, que permitiram o trabalho em paralelo |
| [`01-gustavo.md`](01-gustavo.md) a [`05-joao-caio.md`](05-joao-caio.md) | A tarefa de cada integrante, com o prompt dado à IA e o checklist |

O que cada um efetivamente pediu à IA, e o que precisou corrigir, está em
[`docs/prompts/`](../prompts/).

Durante a entrega estes arquivos ficaram fora do repositório e foram enviados a cada
integrante em privado. Por isso alguns trechos ainda dizem que a pasta "não vai para o
repositório". Eles foram publicados depois, sem alteração, para que as referências do
código e dos registros de IA levem a um arquivo existente.
